# 「舒尔特方格训练」需求文档 V0.1

> 项目名称：舒尔特方格训练  
> 当前版本：V0.1 / MVP 初版  
> 产品类型：专注力训练工具型 App  
> 平台：手机客户端 App，优先移动端竖屏场景  
> 当前范围：仅包含舒尔特方格训练核心流程  
> 评分标准参考：当前项目中的「舒尔特方格评分标准对照表」，包含 3x3、4x4、5x5、7x7 与不同年龄段成绩等级。

---

## 1. 产品背景

舒尔特方格是一种常见的注意力集中训练、视觉搜索训练和反应速度训练工具。用户需要在随机排列的数字方格中，从数字 1 开始，按照递增顺序依次点击所有数字。

本 App 当前阶段定位为一个轻量级训练工具，不做复杂社区、排行榜、账号系统或游戏化成长系统，重点是让用户快速开始一次训练，并在完成后获得清晰的成绩反馈。

---

## 2. 产品定位

「舒尔特方格训练」是一款用于提升注意力集中、视觉搜索速度和反应能力的手机训练工具。

核心特点：

1. 简洁、专注、低干扰。
2. 操作路径短，用户打开后可以快速开始训练。
3. 通过不同方格规格和年龄段，提供适配不同用户的成绩参考。
4. 当前版本只做训练闭环，不做复杂数据沉淀。

---

## 3. 目标用户

### 3.1 成人用户

想通过简单工具进行专注力、视觉搜索能力和反应速度训练的人群。

### 3.2 学生或儿童

在家长或老师辅助下进行注意力训练的儿童或青少年。

### 3.3 日常练习用户

希望通过每日短时间练习保持注意力状态的人群。

---

## 4. 当前版本目标

### 4.1 核心目标

让用户能够完成一次完整的舒尔特方格训练流程：

选择训练规格和年龄段 → 开始训练 → 按顺序点击数字 → 完成后查看成绩结果。

### 4.2 MVP 成功标准

1. 用户可以选择方格规格。
2. 用户可以选择年龄段。
3. 系统可以生成随机数字方格。
4. 用户必须按 1 到 N 的顺序点击。
5. 系统记录完成时间。
6. 系统记录错误次数。
7. 完成后展示成绩等级。
8. 用户可以重新开始训练。

## 6. 核心用户流程

```text
打开 App
  ↓
进入首页 / 训练配置页
  ↓
选择方格规格
  ↓
选择年龄段
  ↓
点击「开始训练」
  ↓
进入训练页
  ↓

  ↓
```

## 7. 页面需求

## 7.1 首页 / 训练配置页

### 页面目标

让用户在开始前完成基础训练配置。

### 页面内容

1. App 名称：舒尔特方格训练。
2. 简短说明：训练专注力、视觉搜索和反应速度。
3. 方格规格选择：
   - 3x3：入门
   - 4x4：初级
   - 5x5：中级
   - 7x7：高级
4. 年龄段选择：
   - 3~5岁
   - 6~10岁
   - 11~17岁
   - 18岁以上
5. 主按钮：开始训练。

### 交互规则

1. 默认选中 5x5 和 18岁以上。
2. 用户必须选择方格规格和年龄段后才能开始。
3. 点击「开始训练」后进入训练页。
4. 当前版本不需要复杂引导页。

---

## 7.2 训练页

### 页面目标

让用户专注完成一次舒尔特方格训练。

### 页面内容

1. 顶部状态区：
   - 当前目标数字，例如：请点击 1
   - 当前计时，例如：00:12.35
   - 错误次数，例如：错误 2 次
2. 中间训练方格：
   - 根据规格显示 3x3、4x4、5x5 或 7x7。
   - 数字随机排列。
3. 底部操作区：
   - 重新开始
   - 退出训练 / 返回

### 交互规则

1. 进入训练页后，系统生成随机数字方格。
2. 用户点击「开始训练」后直接开始计时。
3. 用户点击正确数字：
   - 当前数字标记为已完成。
   - 下一个目标数字递增。
   - 可给出轻微视觉反馈。
4. 用户点击错误数字：
   - 错误次数 +1。
   - 当前目标数字不变。
   - 可给出轻微震动或红色提示。
5. 当用户点击完最后一个数字后：
   - 停止计时。
   - 进入结果页或弹出结果弹窗。

---

## 7.3 结果页 / 结果弹窗

### 页面目标

清晰展示本次训练结果，并引导用户再次训练。

### 页面内容

1. 本次完成时间。
2. 错误次数。
3. 方格规格。
4. 年龄段。
5. 成绩等级：
   - 优
   - 良
   - 及格
   - 未达标
6. 操作按钮：
   - 再来一次
   - 返回首页

### 交互规则

1. 点击「再来一次」：
   - 保持当前方格规格和年龄段。
   - 重新生成随机数字。
   - 开始新一轮训练。
2. 点击「返回首页」：
   - 回到训练配置页。
3. 当前版本不保存历史记录。

## 8. 训练规则

### 8.1 方格规格

| 规格  | 数字范围 | 难度 |
|-----|-----:|----|
| 3x3 |  1~9 | 入门 |
| 4x4 | 1~16 | 初级 |
| 5x5 | 1~25 | 中级 |
| 7x7 | 1~49 | 高级 |

### 8.2 数字生成规则

1. 根据方格规格生成连续数字。
2. 例如 5x5 生成 1 到 25。
3. 每局开始时随机打乱数字顺序。
4. 同一局内数字不重复、不遗漏。

### 8.3 点击规则

1. 用户必须从 1 开始点击。
2. 正确点击后，目标数字 +1。
3. 错误点击不推进进度。
4. 错误点击需要累计错误次数。
5. 全部数字点击完成后，训练结束。

### 8.4 计时规则

1. 点击「开始训练」后开始计时。
2. 点击最后一个正确数字后停止计时。
3. 计时精度建议显示到 0.01 秒。
4. 成绩计算使用秒作为基础单位。

---

## 9. 成绩评分规则

### 9.1 评分维度

当前版本成绩等级主要基于完成时间。

错误次数在当前版本中作为辅助展示指标，不直接影响等级。后续版本可以考虑加入惩罚机制，例如每次错误增加 1 秒或降低评级。

### 9.2 成绩等级

| 等级  | 说明              |
|-----|-----------------|
| 优   | 完成速度非常快         |
| 良   | 完成速度较好          |
| 及格  | 达到基础完成标准        |
| 未达标 | 超过当前规格和年龄段的及格时间 |

### 9.3 评分标准说明

当前评分标准按照以下维度组合判断：

```text
方格规格 + 年龄段 + 完成时间 = 成绩等级
```

例如：

```text
规格：5x5
年龄段：18岁以上
完成时间：18秒
结果：优
```

```text
规格：5x5
年龄段：18岁以上
完成时间：23秒
结果：良
```

```text
规格：5x5
年龄段：18岁以上
完成时间：29秒
结果：及格
```

```text
规格：5x5
年龄段：18岁以上
完成时间：35秒
结果：未达标
```

## 11. UI 设计原则

### 11.1 整体风格

1. 简洁。
2. 专注。
3. 工具型。
4. 低干扰。
5. 不过度游戏化。

### 11.2 视觉建议

1. 背景使用浅色或低饱和色。
2. 方格数字清晰、对比度高。
3. 当前目标数字需要突出。
4. 正确点击反馈轻量化。
5. 错误点击反馈明确但不刺眼。
6. 结果页突出完成时间和等级。

### 11.3 方格设计

1. 每个格子需要有足够点击面积。
2. 7x7 模式下需要特别注意数字可读性。
3. 方格间距不宜过大，避免浪费屏幕空间。
4. 数字居中显示。
5. 已点击数字可以变淡或显示完成态。

## 12. 异常与边界场景

| 场景          | 处理方式                  |
|-------------|-----------------------|
| 用户点击错误数字    | 错误次数 +1，目标数字不变        |
| 用户重复点击已完成数字 | 视为错误点击                |
| 用户中途退出      | 弹出确认或直接返回，当前版本不保存     |
| 用户重新开始      | 重新生成数字并重置计时、错误次数      |
| 7x7 屏幕显示过密  | 自动调整字号和格子间距           |
| App 切到后台    | MVP 可暂停计时或继续计时，建议暂停计时 |
| 横竖屏切换       | 当前版本建议锁定竖屏            |

## 13. 非功能需求

### 13.1 性能要求

1. 页面切换流畅。
2. 点击反馈无明显延迟。
3. 计时显示稳定。
4. 生成方格应瞬时完成。

### 13.2 可用性要求

1. 用户 3步 内可以开始训练。
2. 训练页不能有过多干扰元素。
3. 结果反馈必须清晰易懂。
4. 儿童用户也能理解基础操作。

### 13.3 可访问性要求

1. 数字字号足够清晰。
2. 颜色不能只依赖红绿区分。
3. 点击区域不宜过小。
4. 结果等级需要文字说明，不仅用颜色表达。

## 18. 初版结论

当前项目的第一阶段应优先完成一个极简但完整的训练闭环：

```text
配置训练参数 → 开始训练 → 顺序点击数字 → 记录时间和错误 → 展示成绩 → 重新训练
```

这个版本不追求功能复杂，而是要先验证核心体验是否顺畅：用户是否能快速进入训练、训练过程是否专注、结果反馈是否清晰。后续再围绕历史记录、训练计划、数据分析和多模式训练逐步扩展。
