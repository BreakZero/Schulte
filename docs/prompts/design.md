请帮我设计一个手机客户端 APP 的高保真原型稿，APP 名称为「舒尔特方格训练」。

这是一个专注于舒尔特方格训练的轻量级工具型 APP。当前版本为 V0.3，在原有舒尔特方格训练闭环基础上，新增「设置入口」「AI 配置」「训练报告」「AI 增强分析建议」能力。

一、产品定位

「舒尔特方格训练」是一款用于注意力集中训练、视觉搜索训练和反应速度训练的手机 APP。

用户选择方格规格和年龄段后，系统随机生成数字方格。用户需要从 1 开始，按照数字递增顺序依次点击所有数字。系统记录完成时间、错误次数，并在完成后根据评分标准展示成绩等级。

V0.3 新增能力：
1. 首页提供设置入口。
2. 设置页可以配置 AI API Key、Base URL、模型名称。
3. 结果页展示基础训练报告。
4. 用户可以点击「AI 分析」生成增强训练建议。
5. AI 功能是可选增强能力，没有配置 API Key 时，基础训练和基础报告仍然可用。

二、目标用户

1. 想训练专注力和视觉搜索能力的成年人。
2. 想进行注意力训练的学生或儿童。
3. 想通过简单工具进行每日练习的用户。
4. 对训练结果有进一步分析需求，希望获得个性化训练建议的用户。

三、设计风格

整体风格要求：
1. 简洁、专注、低干扰。
2. 偏工具型 APP，不要游戏化过重。
3. UI 清爽，有轻微科技感，但不要像健身游戏或儿童游戏。
4. 使用现代移动端设计语言，适合 Android / iOS。
5. 推荐使用 Material 3 风格，方便后续用 Kotlin Multiplatform + Compose 实现。
6. 背景使用浅色、低饱和色，例如浅灰白、淡蓝、淡青。
7. 主色建议使用冷静、专注感的蓝色或蓝绿色。
8. 卡片使用圆角、轻阴影、充足留白。
9. 数字方格需要视觉清晰，对比度高。
10. 整体不要拥挤，训练页要最大程度减少干扰。

四、设备与画布要求

请设计移动端竖屏高保真原型：
- 画布尺寸：390 × 844 或 393 × 852
- 适配 iPhone / Android 主流手机
- 每个页面作为独立 Frame 展示
- 所有 UI 文案使用中文
- 保留状态栏和安全区域
- 底部按钮需要考虑手势导航安全距离

五、需要设计的页面

请生成以下 6 个核心页面：

页面 1：首页 / 训练配置页

页面目标：
让用户快速完成训练配置并开始训练。

页面内容：
1. 顶部：
    - App 名称：「舒尔特方格训练」
    - 右上角设置图标按钮
2. 主标题：
    - 「开始一次专注力训练」
3. 副标题：
    - 「按顺序点击数字，训练视觉搜索与注意力集中」
4. 今日轻量提示卡片：
    - 「建议每日练习 3～5 分钟」
    - 「保持自然呼吸，尽量不要移动视线中心」
5. 方格规格选择：
    - 3×3 入门
    - 4×4 初级
    - 5×5 中级
    - 7×7 高级
      默认选中：5×5
6. 年龄段选择：
    - 3～5岁
    - 6～10岁
    - 11～17岁
    - 18岁以上
      默认选中：18岁以上
7. 训练模式选择：
    - 标准模式
    - 辅助模式
      默认选中：标准模式
      标准模式说明：「点击后仅短暂反馈，不持续标记」
      辅助模式说明：「显示已完成标记，成绩仅供练习参考」
8. 主按钮：
    - 「开始训练」

交互状态表达：
- 当前选中的规格、年龄段、训练模式需要有明显选中态。
- 设置入口不抢主视觉，但要容易找到。

页面 2：训练页 / 标准模式进行中

页面目标：
让用户专注完成一次舒尔特方格训练。

页面内容：
1. 顶部导航：
    - 左侧返回按钮
    - 中间标题：「标准训练」
    - 右侧可以为空或放置暂停按钮
2. 顶部状态区：
    - 当前目标：「请点击 13」
    - 计时：「00:12.35」
    - 错误：「错误 1 次」
3. 中间核心区域：
    - 一个 5×5 舒尔特方格
    - 数字 1～25 随机分布
    - 数字居中显示
    - 格子圆角，边界清晰
    - 当前页面展示训练进行中的状态
4. 底部操作区：
    - 次要按钮：「重新开始」
    - 次要按钮：「退出训练」

关键规则：
- 标准模式下，正确点击后不要持续置灰、不要隐藏数字、不要显示长期完成标记。
- 可以用某一个数字格子展示 100～200ms 的短暂点击反馈，例如轻微高亮或缩放。
- 错误点击可以有轻微红色提示，但不要过度游戏化。
- 训练页不要出现排行榜、广告、复杂动画、历史趋势等干扰元素。

页面 3：结果报告页 / 基础报告 + AI 分析入口

页面目标：
训练完成后展示基础成绩，并提供 AI 分析入口。

页面内容：
1. 顶部：
    - 标题：「本次训练报告」
    - 副标题：「完成一次 5×5 标准训练」
2. 成绩核心卡片：
    - 大号显示完成时间：「18.42 秒」
    - 成绩等级 Badge：「优」
    - 一句反馈：「你的视觉搜索速度表现很好」
3. 数据概览卡片：
    - 方格规格：5×5
    - 年龄段：18岁以上
    - 训练模式：标准模式
    - 错误次数：1 次
    - 完成时间：18.42 秒
4. 评分说明卡片：
    - 「根据当前规格、年龄段与完成时间进行等级判断」
    - 「错误次数暂作为辅助指标展示」
5. AI 增强分析卡片：
    - 标题：「AI 增强分析」
    - 说明：「让 AI 根据本次训练表现，生成专注力训练建议」
    - 主按钮：「生成 AI 分析」
    - 小字说明：「AI 建议仅供训练参考，不作为医学或心理诊断」
6. 底部操作：
    - 主按钮：「再来一次」
    - 次按钮：「返回首页」

视觉要求：
- 完成时间是结果页第一视觉重点。
- 成绩等级醒目，但不要夸张。
- AI 分析入口作为增强能力展示，不要压过基础报告。

页面 4：AI 分析结果页 / 增强训练建议

页面目标：
展示 AI 对训练报告的分析结果，给用户可执行的训练建议。

页面内容：
1. 顶部标题：
    - 「AI 训练建议」
2. 总结卡片：
    - 标题：「本次表现总结」
    - 内容示例：「你在 5×5 标准模式下完成时间为 18.42 秒，错误 1 次，整体表现优秀。建议继续保持标准模式训练，并逐步提高稳定性。」
3. 时间分析卡片：
    - 标题：「速度表现」
    - 内容示例：「完成时间已达到当前年龄段优秀水平，可以尝试保持速度的同时降低错误次数。」
4. 错误分析卡片：
    - 标题：「错误情况」
    - 内容示例：「本次出现 1 次错误，可能来自目标切换时的注意力偏移。建议训练时先锁定下一个目标，再点击。」
5. 下一次训练目标卡片：
    - 标题：「下一次目标」
    - 内容：
        - 「目标时间：18 秒以内」
        - 「错误次数：0 次」
        - 「推荐规格：5×5 标准模式」
6. 增强训练建议卡片：
    - 标题：「增强训练建议」
    - 列表：
        - 「每天练习 3 组，每组间隔 30 秒」
        - 「优先保证准确率，再提升速度」
        - 「完成 5×5 稳定后，再尝试 7×7」
7. 底部按钮：
    - 「再练一次」
    - 「返回报告」

视觉要求：
- AI 分析页要像训练教练报告，不要像聊天界面。
- 使用分组卡片，提高可读性。
- 建议内容要短句化、可执行。
- 可以加入轻量 AI 图标，但不要过度科技化。

页面 5：AI 未配置状态 / 结果页中的降级状态

页面目标：
当用户没有配置 API Key 或 Base URL 时，展示清晰降级状态。

页面内容：
1. 保留基础训练报告。
2. AI 分析卡片显示未配置状态：
    - 标题：「AI 增强分析未启用」
    - 说明：「配置 API Key 和 Base URL 后，可以生成个性化训练建议」
    - 主按钮：「前往设置」
    - 次要文字：「不配置 AI 也可以正常使用基础训练和成绩报告」
3. 其他操作：
    - 「再来一次」
    - 「返回首页」

视觉要求：
- 不要把未配置状态设计成错误或失败。
- 表达为可选增强能力。
- 避免给用户造成必须配置才能使用的误解。

页面 6：设置页 / AI 配置

页面目标：
让用户管理基础设置和 AI 服务配置。

页面内容：
1. 顶部导航：
    - 返回按钮
    - 标题：「设置」
2. 分组一：训练设置
    - 默认方格规格：5×5
    - 默认年龄段：18岁以上
    - 默认训练模式：标准模式
    - 开关：「辅助模式显示已完成标记」
    - 辅助说明：「开启后成绩仅作为练习参考」
3. 分组二：AI 设置
    - 开关：「启用 AI 分析」
    - 输入框：「API Key」
        - placeholder：「请输入你的 API Key」
        - 右侧提供显示 / 隐藏按钮
    - 输入框：「Base URL」
        - placeholder：「例如：https://api.openai.com/v1」
    - 输入框：「模型名称」
        - placeholder：「例如：gpt-4o-mini」
    - 按钮：「测试连接」
    - 按钮：「清除配置」
4. 分组三：隐私与说明
    - 「API Key 仅保存在本地设备」
    - 「训练报告仅在用户点击 AI 分析时发送」
    - 「AI 建议仅供训练参考，不作为医学或心理诊断」
5. 底部按钮：
    - 「保存设置」

视觉要求：
- 设置页要清晰、可信、安全感强。
- API Key 输入框需要有安全输入样式。
- Base URL 和模型名称属于高级配置，但仍要清楚可见。
- 测试连接结果可以设计为成功状态：「连接成功」或失败状态：「连接失败，请检查配置」。

七、舒尔特方格视觉细节

1. 数字需要足够大，7×7 时也要保证可读性。
2. 格子间距适中，不要太挤。
3. 方格整体居中。
4. 标准模式下不要持续标记已点击数字。
5. 只允许短暂点击反馈，例如轻微高亮、轻微缩放、短暂 ripple。
6. 辅助模式可以展示已完成标记，但必须弱化，并在页面中提示「辅助模式成绩仅供参考」。
